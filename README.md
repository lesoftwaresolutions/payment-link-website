# Payment Pending Holding Page

Production-ready React, Vite, and Tailwind CSS holding page for Le Software Solutions payment status messaging.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Vercel

## Local Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Deployment

This project includes a production-ready `vercel.json` configured for Vite:

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

Deploy by importing this repository into Vercel and selecting the Vite framework preset.
